# Conception d'interface

1. Respecte le design system existant ; sinon définis un petit jeu de couleurs, tailles et espacements.
2. Guide le regard : une action principale par écran, une hiérarchie nette.
3. Dessine aussi les états : vide, chargement, erreur, succès.
4. Conçois du mobile vers le bureau et contrôle plusieurs largeurs.
5. Assure l'accessibilité : contraste, clavier, focus visible, libellés, HTML sémantique.
6. Vérifie le résultat rendu, avec une capture lorsque c'est possible.
