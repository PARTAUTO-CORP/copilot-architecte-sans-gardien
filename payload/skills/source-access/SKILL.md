# Accès aux sources

1. Identifie le type de source : fichier, URL, dépôt, ticket, page, base.
2. Choisis le meilleur moyen disponible : outil natif, MCP, CLI, API ou navigateur. Essaie le suivant si le premier échoue.
3. Installe ou configure ce qui manque si les identifiants sont disponibles.
4. Prouve l'accès en lisant réellement le contenu, puis conserve la référence exacte.
5. Si rien ne fonctionne, déclare `BLOCKED` et liste ce qui a été tenté.
