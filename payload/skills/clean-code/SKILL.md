# Clean code

1. Écris le changement le plus petit qui résout entièrement le problème.
2. Réutilise ce qui existe : code du projet, bibliothèque standard, dépendances déjà installées.
3. Donne des noms précis. Commente le pourquoi, pas le quoi.
4. Une fonction fait une chose ; sors tôt pour limiter l'imbrication.
5. Supprime le code mort. N'ajoute une abstraction que pour un besoin présent.
6. Traite les erreurs là où tu peux agir ; ne les avale pas.
7. Refactorise avec les tests au vert, séparément du changement fonctionnel.
