# Intelligence de fichiers

1. Identifie le format réel, sans te fier seulement à l'extension.
2. Extrais le contenu avec le meilleur outil disponible et installe celui qui manque.
3. Préserve la structure : tableaux, titres, pages, feuilles.
4. Cite le fichier et la page, la feuille ou la ligne pour chaque information clé.
5. Signale ce qui n'a pas été extrait correctement (scan illisible, fichier protégé).
6. L'extraction décrit le fichier ; la vérité du projet se décide en recoupant les sources.
