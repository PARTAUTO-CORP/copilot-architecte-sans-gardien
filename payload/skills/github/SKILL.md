# GitHub

1. `gh` est GitHub CLI et `copilot` est Copilot CLI : ce sont deux outils distincts.
2. Vérifie l'accès avec `gh auth status` ou un appel réel à un outil MCP.
3. Lis les données réelles : diff, checks, commentaires et logs d'Actions, et non le seul résumé.
4. Crée branches, commits, pull requests, issues et releases quand la tâche le demande.
5. Cite les numéros, SHA et URL dans le rapport.
6. Après une écriture, relis l'état distant pour la confirmer.
