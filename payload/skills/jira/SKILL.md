# Jira

1. Une skill ne crée pas de connexion : vérifie d'abord l'accès réel (MCP configuré, API avec jeton).
2. Si aucun accès n'existe, configure-le quand les identifiants sont disponibles, sinon déclare `BLOCKED` et précise ce qui manque.
3. Lis la description, les critères d'acceptation, les commentaires et les liens.
4. Transforme les critères en vérifications concrètes, et signale les manques.
5. Crée, commente ou fais évoluer les tickets quand la tâche le demande, puis relis pour confirmer.
6. Cite chaque clé de ticket utilisée.
